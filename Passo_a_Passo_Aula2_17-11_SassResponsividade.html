TODO 1 · Editar o angular.json

Arquivo: angular.json → projects > projeto-angular-sctec > architect > build > options
"options": {
  "browser": "src/main.ts",
  "tsConfig": "tsconfig.app.json",
  "assets": [ { "glob": "**/*", "input": "public" } ],
  "styles": ["src/styles.scss"],
  "inlineStyleLanguage": "scss",
  "stylePreprocessorOptions": {
    "includePaths": ["src/styles"]
  }
},
ChaveO que faz
stylesTroca o CSS global de styles.css para styles.scss.
inlineStyleLanguagePermite escrever SCSS também em styles: [...] dentro do @Component.
includePathsDiz ao Sass onde procurar arquivos: é o que faz o @use 'mixins' funcionar em qualquer componente.

O arquivo src/styles.scss ainda não existe: ele chega na Etapa B. Por isso o servidor continua parado.

TODO 2 · Mapa + @each = variáveis CSS

Arquivo: src/styles/_tokens.scss
@use 'variaveis' as *;

:root {
  @each $nome, $valor in $cores {
    --#{$nome}: #{$valor};
  }
  --raio: #{$raio};
  --sombra: #{$sombra};
}

TODO 3 · Mixin de breakpoint (mobile-first)

Arquivo: src/styles/_mixins.scss → corpo do @mixin a-partir-de($bp). Apague a linha provisória @if false { @content; }.
@mixin a-partir-de($bp) {
  @if not map.has-key($breakpoints, $bp) {
    @error "Breakpoint '#{$bp}' não existe. Use um destes: #{map.keys($breakpoints)}";
  }
  @media (min-width: map.get($breakpoints, $bp)) {
    @content;
  }
}

Testar: no desktop o menu fica em linha e o subtítulo do cabeçalho aparece. Teste o @error: escreva @include a-partir-de(tablet) em algum .scss, leia a mensagem no terminal e desfaça.

TODO 4 · Menu responsivo

Arquivos: src/app/core/layout/header/header.ts (A) e header.html (B e C)
// A) header.ts (dentro da classe Header, abaixo do menuAberto)
alternarMenu(): void {
  this.menuAberto.update((aberto) => !aberto);
}

fecharMenu(): void {
  this.menuAberto.set(false);
}
<!-- B) header.html: o botão, entre a div "marca" e o nav -->
<button
  type="button"
  class="menu-toggle"
  (click)="alternarMenu()"
  [attr.aria-expanded]="menuAberto()"
  aria-controls="menu-principal"
  aria-label="Abrir ou fechar o menu"
>
  {{ menuAberto() ? '✕' : '☰' }}
</button>

<!-- C) no nav, acrescente (click)="fecharMenu()" -->
<nav id="menu-principal" aria-label="Menu principal" [class.aberto]="menuAberto()" (click)="fecharMenu()">

Testar: F12 → Ctrl + Shift + M (modo dispositivo) → 375 px: aparece o ☰; clicar abre o menu em coluna; clicar num link fecha. Em 768 px o botão some e o menu fica em linha.
