Etapa 0 · Parar o servidor e salvar a Aula 2

Pare o ng serve (Ctrl + C). Com o servidor ligado, o Windows pode bloquear arquivos e a instalação da Etapa A falha.

ComandoO que faz
git statusMostra se a pasta é um repositório Git e o que mudou desde o último commit.

Cenário 1 · O projeto já tem Git (o git status respondeu normalmente)

git add .Prepara todas as alterações para o commit.
git commit --message "feat(estilo): aula 2"Cria um ponto de restauração com a Aula 2 pronta. Se a instalação der problema, você volta para cá.

Cenário 2 · Apareceu fatal: not a git repository

git initTransforma a pasta do projeto em um repositório Git.
git add .Prepara todos os arquivos (o .gitignore deixa o node_modules de fora).
git commit --message "feat(estilo): aula 2"Cria o primeiro ponto de restauração.

Cenário 3 · O Git pediu nome e e-mail

git config --global user.name "Seu Nome"Define o nome do autor dos commits neste computador.
git config --global user.email "seu@email.com"Define o e-mail do autor. Depois, repita o git commit.

Cenário 4 · git não é reconhecido como comando

Backup manual: copie a pasta src e os arquivos angular.json, package.json e package-lock.json para fora do projeto (por exemplo, Documentos\backup-aula2). Hoje isso é ainda mais importante, porque a instalação altera o package.json.

Etapa A · Instalar as bibliotecas (com o servidor parado)

ComandoO que faz
npm view @angular/material version peerDependenciesConsulta, sem instalar nada, a versão mais recente do Angular Material e com quais versões do Angular ela funciona (procure @angular/core: ^22...).
npm view ngx-mask version peerDependenciesFaz a mesma conferência para a biblioteca de terceiros ngx-mask.
ng add @angular/materialInstala o Angular Material e o CDK e configura o projeto: adiciona as fontes Roboto e Material Symbols no index.html e um tema no styles.scss. Se fizer perguntas, confirme com Y e aceite a opção padrão com Enter (o tema será personalizado no TODO 2).
npm install ngx-maskSó baixa a ngx-mask para o node_modules e registra no package.json. A configuração é manual (TODO 1).
git diff --statLista quais arquivos as instalações alteraram (package.json, package-lock.json, index.html, styles.scss). Sem Git, pule este comando.
Se você rodar o projeto agora, ele quebra (e está tudo bem)@use rules must be written before any other rules. O ng add escreveu o tema antes dos nossos @use no styles.scss, e no Sass todos os @use vêm no topo. Não precisa corrigir à mão: o styles.scss da Etapa B já vem organizado.
Se der npm ERR! ERESOLVEÉ conflito de versão. Não use --force: chame o professor e confira o resultado do npm view.

Etapa B · Trocar o src

  1. No VS Code, apague a pasta src/app.
  2. No repositório M2S06, copie Aula3_MaterialTerceiros/src e cole dentro de projeto-angular-sctec ("Substituir os arquivos no destino"). Isso substitui também o index.html (com as fontes) e o styles.scss (com os @use no topo).
  3. Ligue o servidor:
ng serve --openCompila o projeto, sobe o servidor em http://localhost:4200 e abre o navegador.
Normal neste momentoO terminal mostra erros como 'mat-form-field' is not a known element: os componentes do Material ainda não foram importados. O TODO 1 resolve.

TODO 6 · Aviso com MatSnackBar

Arquivo: src/app/features/alunos/cadastro-aluno/cadastro-aluno.ts
// A) import no topo e o service na classe
import { MatSnackBar } from '@angular/material/snack-bar';

private snackBar = inject(MatSnackBar);

// B) e C) dentro do método enviar()
enviar(): void {
  if (this.form.invalid) {
    this.form.markAllAsTouched();
    this.snackBar.open('Confira os campos destacados em vermelho.', 'OK', { duration: 3000 });
    return;
  }
  const dados = this.form.getRawValue();
  this.alunoSalvo.set({ ...dados, cadastradoEm: new Date() });
  this.snackBar.open(`Aluno ${dados.nome} cadastrado com sucesso!`, 'Fechar', { duration: 4000 });
}

Fechamento

Em um segundo terminal (botão + no painel do terminal), para não parar o ng serve:

ComandoO que faz
ng buildGera a versão de produção e confere se não há erros. Hoje deve aparecer um aviso de budget (explicado abaixo).
Aviso de budgetbundle initial exceeded maximum budget (≈524 kB > 500 kB): o cabeçalho é carregado logo no início e agora usa o Material. É um aviso, não um erro. Decisão consciente: no angular.json → configurations > production > budgets, no item "type": "initial", troque "maximumWarning": "500kB" por "700kB" e rode ng build de novo.
git add .Prepara todas as alterações da aula (incluindo package.json e package-lock.json com as bibliotecas novas).
git commit --message "feat(ui): angular material e ngx-mask"Salva a Aula 3 como um novo ponto de restauração.
git pushSó se o projeto já estiver ligado ao GitHub: envia os commits. Se ainda não estiver, veja o quadro "Ainda não ligou o projeto ao GitHub?" do passo a passo da Aula 1.
Em outro computadorDepois de clonar o projeto, rode npm install: ele lê o package.json e baixa o Material e a ngx-mask para o node_modules, que não vai para o GitHub.
